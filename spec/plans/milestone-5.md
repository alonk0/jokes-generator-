**מקורות:** `MILESTONES.md` (Milestone 5), `ARCHITECTURE.md` (1.2, 2.6, 2.7, 2.8), `PRD.md`, `CLAUDE.md`.

## 1. נקודת פתיחה (מצב הקוד היום)

- האפליקציה שלמה מבחינת פיצ'רים (Milestones 1–4 אושרו ונדחפו). ה-repo המקומי כבר מחובר ל-GitHub: `https://github.com/alonk0/jokes-generator-.git`, ענף `main`, ללא שינויים פתוחים.
- `app/api/joke/route.ts` כבר מגדיר `maxDuration = 60` ו-timeout פנימי של 50 שניות, מחזיר `Cache-Control: no-store, no-transform` ל-SSE ולא רושם ללוג נושאים או בדיחות.
- `next.config.ts` כבר משתמש ב-`VERCEL_GIT_COMMIT_SHA` כגרסת ה-Service Worker — כל Deployment ב-Vercel יקבל Cache חדש.
- הטיפול בתשובת `429` (גם עם גוף HTML/טקסט) כבר קיים ונבדק ב-Vitest (`lib/errors.ts`, `lib/jokeClient.ts`).
- `.env.example` קיים עם `OPENAI_API_KEY` בלבד.

**מסקנה:** ה-Milestone הזה הוא בעיקר **הגדרת תשתית ובדיקות**, לא פיתוח. שינויי הקוד קטנים: סקריפט בדיקה לחסימת הקצב ותיעוד.

## 3. שלבי הביצוע

### 3.1 הכנה מקומית (Claude)
1. להריץ `npm run lint`, `npm test`, `npm run build` ולוודא שהכול עובר לפני הפריסה.
2. לוודא ש-`.env` אינו ב-Git (`git ls-files`) ושאין מפתח או טקסט ההוראות לשרת בקוד הלקוח (חיפוש ב-`.next/static` אחרי build אחר `sk-`, `OPENAI` וקטע מתוך `INSTRUCTIONS`).

### 3.2 חיבור Vercel (המשתמש, בהדרכת Claude)
1. הרשמה ל-Vercel עם חשבון GitHub (תוכנית Hobby — לשימוש אישי לא-מסחרי; לציין זאת למשתמש).
2. **Add New → Project** → בחירת ה-repo `jokes-generator-` → Framework: Next.js (מזוהה אוטומטית), בלי לשנות Build/Install/Root Directory.
3. **לא** להזין משתני סביבה במסך הייבוא (שם הם מוגדרים כברירת מחדל לכל הסביבות, כולל Preview). ללחוץ Deploy. הפריסה הראשונה תעלה, אבל יצירת בדיחה עוד תיכשל עם הודעת שגיאה — זה צפוי.
4. **Settings → Environment Variables:** הוספת `OPENAI_API_KEY` וסימון **Production בלבד** (לבטל Preview ו-Development). מומלץ מפתח OpenAI נפרד ל-Production, אם נוח.
5. **Settings → Git:** לוודא ש-Production Branch הוא `main`.
6. **Settings → Functions / Build logs:** לוודא שגרסת Node.js היא 24.x ושהבנייה עברה בלי שגיאות.
7. לרשום את כתובת האתר (`https://<project>.vercel.app`) ולמסור אותה ל-Claude. **לא לשתף אותה עם אחרים עד סיום 3.3.**

### 3.3 כלל Rate Limiting ב-WAF (המשתמש, בהדרכת Claude)
ב-Vercel: **Firewall → Configure → + New Rule**:
- שם: `joke-rate-limit`
- **If:** `Request Path` **equals** `/api/joke` **AND** `Method` **equals** `POST`
- **Then:** `Rate Limit` — `Fixed Window`, `60` שניות, `5` בקשות, מפתח: `IP`, פעולה בחריגה: `429 Too Many Requests`
- **Save** ואז **Review Changes → Publish** (הכלל לא פעיל עד ה-Publish).

### 3.4 קוד ותיעוד (Claude)
1. **`scripts/check-rate-limit.mjs`** + פקודה `npm run check:rate-limit -- <url>`:
   - שולח 6 בקשות `POST /api/joke` ברצף, עם נושא באורך 101 תווים — **בקשה לא תקינה**, כך שגם אם עברה את ה-WAF השרת מחזיר `400` ו**לא פונה ל-OpenAI** (בדיקה בלי עלות).
   - מדפיס לכל בקשה את הסטטוס. הצלחה: 5 ראשונות `400`, השישית `429`. אם הבדיקה התחילה סמוך לסוף חלון — להריץ שוב אחרי דקה.
   - בלי תלויות חדשות (`fetch` מובנה ב-Node).
2. **`ARCHITECTURE.md` — ADR-4** (מותר לפי `CLAUDE.md`): תיעוד ההגדרות שבוצעו ב-Vercel ואינן נובעות מה-repo: שם הפרויקט וכתובתו, ענף Production, היקף משתנה הסביבה (Production בלבד), פרטי כלל ה-WAF, ואיך מוודאים שהוא פעיל.
3. **`CLAUDE.md` — "פקודות הרצה":** הוספת שורה לכתובת האתר החי ולפקודת בדיקת חסימת הקצב.
4. להריץ שוב lint, בדיקות ו-build.

### 3.5 Push ראשון לבדיקת פריסה אוטומטית (Claude, באישור המשתמש)
- **לעצור ולבקש אישור ל-push** (דרישת `CLAUDE.md`). ה-Push כולל את קובצי שלב 3.4.
- אחרי ה-Push: לוודא ב-Vercel (או דרך המשתמש) שנוצר Production Deployment חדש אוטומטית, שהוא תקין, ושהוא כולל את משתנה הסביבה (משתני סביבה נכנסים לתוקף רק בפריסה חדשה — ה-Push הזה גם פותר את זה).
- סימון ה-✅ ל-Milestone **לא** נעשה ב-Push הזה; הוא יקרה רק בדחיפה שבסוף, אחרי אישור המשתמש.

### 3.6 בדיקות קבלה באתר החי

**Claude בודק (מהמחשב, Terminal ו-Browser המובנה):**
| תחום | איך |
|---|---|
| HTTPS ו-Deployment | פתיחת האתר; בדיקת התעודה; Deployment מקושר ל-commit האחרון |
| Streaming אמיתי (לא נצבר) | `curl -N` לנושא אחד — המקטעים מגיעים בהדרגה, ומסתיימים ב-`complete` |
| כותרות | ל-API: `no-store`; לעמוד: `nosniff`, `Referrer-Policy`; `/sw.js` לא נשמר ב-Cache |
| Rate Limiting | `npm run check:rate-limit -- <url>`: הבקשה השישית `429`. מיד אחר כך (באותה דקה) לחיצה על "צור בדיחה" בדפדפן → הודעת הגבלת הקצב בעברית |
| "לפני OpenAI" | הבקשות בסקריפט לא תקינות ולכן לא מגיעות ל-OpenAI בכל מקרה; בנוסף, ב-Vercel → Firewall/Logs רואים שהבקשה החסומה לא הפעילה את ה-Function |
| בקשות ישירות ל-API | נושא מעל 100 תווים, JSON שבור, Content-Type שגוי, Origin זר → נדחים |
| זרימות הממשק | נושא ריק / "חתולים" / נושא באנגלית / נושא רגיש; 100 תווים והדבקה ארוכה; כפתור ✕; "יוצר בדיחה..."; עצירה (טקסט חלקי נשאר, אין העתקה); העתקה אחרי השלמה ו"הועתק!"; בדיחה חדשה מחליפה את הקודמת |
| סודות | חיפוש בקובצי ה-JS של האתר החי אחר `sk-` וטקסט ההוראות; `git grep` ב-repo |
| לוגים | ב-Vercel Logs (דרך המשתמש) — אין נושאים או טקסט בדיחות, רק סטטוסים |

**המשתמש בודק (במכשירים שלו, לפי רשימה פשוטה ש-Claude ייתן):**
- התקנה כ-PWA: Chrome/Edge במחשב, Chrome באנדרואיד ו/או Safari באייפון ("הוסף למסך הבית") — שם ואייקון נכונים, אין כפתור התקנה באתר.
- Offline: אחרי פתיחה מחוברת — מצב טיסה ← פתיחת האפליקציה ← הממשק מופיע עם העיצוב והגופנים; "צור בדיחה" מציג הודעה בעברית.
- ניתוק באמצע יצירה (מצב טיסה בזמן שהבדיחה נכתבת) → הודעת שגיאה, הטקסט החלקי נשאר, אפשר לנסות שוב.
- מעבר מהיר על המראה בטלפון, בטאבלט (אם יש) ובמחשב, ב-Safari וב-Chrome לפחות.

**כשל בשירות ה-AI באתר החי:** אין דרך לגרום לכשל אמיתי בלי לשנות הגדרות. הצעה: המשתמש מחליף זמנית את ערך `OPENAI_API_KEY` ב-Vercel בערך שגוי → Redeploy → "צור בדיחה" צריך להציג הודעת שגיאה בעברית → החזרת המפתח הנכון → Redeploy. (אם המשתמש מעדיף לא — נסתמך על הבדיקה המקומית מ-Milestone 3, ונציין זאת בתוצאות.)

## 5. סיכונים ונקודות לתשומת לב
- **כל Push ל-`main` = פריסה לאוויר.** לכן כל Push ב-Milestone הזה רק באישור מפורש.
- **הכתובת ציבורית מרגע הפריסה הראשונה**, גם לפני WAF. לא לשתף אותה עד שהכלל פורסם; הסיכון בפער הקצר הזה קטן כל עוד אין מפתח מוגדר (הפריסה הראשונה בלי מפתח).
- WAF אינו הגנה מוחלטת על התקציב (ARCHITECTURE 1.2) — מגבלת ההוצאה ב-OpenAI היא קו ההגנה האחרון.
- בדיקת ה-WAF משתמשת בכתובת ה-IP של המחשב; אם הסקריפט והדפדפן יוצאים מכתובות שונות (VPN וכד'), בדיקת ההודעה בדפדפן לא תיחסם — להריץ את שניהם מאותה רשת.
- עלות הבדיקות: כמה עשרות בדיחות לכל היותר — זניחה, אבל תיראה ב-Usage.
